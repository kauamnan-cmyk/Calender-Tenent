# Calender-Tenent
Calendário escolar interativo para consultar eventos, feriados, avaliações e reuniões em um só lugar. Oferece visualizações anual, mensal e semanal, busca e filtros por categoria, além de detalhes dos eventos com imagens e anexos. Desenvolvido com React, TypeScript e Tailwind CSS, com interface responsiva e dados demonstrativos.
