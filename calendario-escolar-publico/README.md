# Calendario escolar

Interface de demonstracao de um calendario escolar com React, TypeScript,
TanStack Start e Tailwind CSS. Eventos e anexos sao exemplos definidos em codigo.
Esta versao usa estado em memoria e nao precisa de credenciais de producao.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Validacao

```sh
npm test
npm run build
```

## Publicacao do codigo

Nao inclua arquivos .env, credenciais, dumps de banco, dados locais de testes
ou pacotes de implantacao. Esses arquivos estao cobertos pelo .gitignore.
Variaveis com prefixo VITE_ sao publicas no navegador: nunca use esse prefixo
para senhas ou chaves privadas.

Para publicar uma copia independente, use somente os arquivos da exportacao
limpa e inicialize um novo repositorio. O historico do repositorio original
contem configuracoes antigas e nao deve acompanhar a copia publica.

Projeto originalmente desenvolvido com [Lovable](https://lovable.dev).
